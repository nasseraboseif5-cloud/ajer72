صدقة جارية — نسخة مطوّرة (واجهة ويب/PWA)

التعديلات:
- اسم القسم موحّد إلى «الأدعية» فقط في كل مواضع الواجهة.
- القرآن: عرض نص المصحف حسب صفحات 1–604 من Al Quran Cloud API، مع السابق/التالي، الانتقال لرقم صفحة، اختيار السورة، وحفظ آخر صفحة.
- الاستماع: تحميل قائمة الإصدارات الصوتية العربية المتاحة من Al Quran Cloud، واختيار السورة وتشغيلها عبر المشغل.
- الأدعية: أدعية قرآنية ونبوية مصنفة وقابلة للبحث والحفظ مع ذكر المصدر.
- الأحاديث: مجموعة منتقاة قصيرة مع المراجع والبحث المحلي، ورابط مباشر للموسوعة الحديثية للدرر السنية للتحقق والبحث الموسع.
- الأذكار: صفحة بداية محدودة؛ بعض الأذكار مختصرة بعلامة حذف، وليست مكتبة مكتملة ولا تُعرض باعتبارها نصوصًا كاملة.
- مواقيت الصلاة: يكتب المستخدم المدينة وتُجلب المواقيت من AlAdhan (طريقة 5).
- القبلة: تستخدم إذن الموقع لحساب الاتجاه، ولا تحفظ إحداثيات المستخدم.
- المسبحة والمحفوظات والمظهر الداكن تحفظ محليًا على الجهاز.

مهم جدًا:
1) هذا إصدار ويب مطوّر، وليس APK أصليًا. يعمل عبر المتصفح ويمكن تثبيته كـ PWA إذا دعم المتصفح ذلك.
2) يلزم اتصال إنترنت للقرآن والصوت والمواقيت والقبلة.
3) الصوت يعتمد على الإصدارات التي تعلنها واجهة Al Quran Cloud وقت التشغيل؛ لم ننسخ ملفات صوت من تطبيق Quran Player الذي أرسلته، ولم نتحقق من وجود كل قارئ بعينه. توافر كل تسجيل وشروط إعادة استخدامه تخضع لمصدره.
4) نص القرآن يعرض صفحة بصفحة وفق بيانات API، لكنه ليس صورة مصحف مطبوعة ولا يضمن محاكاة الرسم والتوزيع الطباعي حرفيًا.
5) التفسير الكامل، ختمة القرآن، التنبيهات والأذان التلقائي بالخلفية، وقاعدة بيانات موسعة للأحاديث والأذكار والأدعية لم تكتمل في هذا الإصدار. لا توجد موافقة من الدرر السنية على نسخ موسوعتها؛ لا تُنسب إليها قاعدة بيانات داخل التطبيق.
6) مواقيت الصلاة تحتاج مراجعة المدينة وطريقة الحساب والتوقيت المحلي. لا توجد ميزة أذان تلقائي في الخلفية.
7) لا تعتمد على العينة المحدودة باعتبارها مكتبة دينية شاملة. راجع النصوص والمصادر قبل نشر التطبيق على نطاق واسع.

النشر:
- فك الضغط وارفع محتويات مجلد sadaqa-jariya إلى مستودع GitHub Pages.
- بعد النشر افتح الموقع عبر HTTPS.
- لو عندك نسخة قديمة مثبتة، افتح الموقع من جديد أو امسح بيانات الموقع لتحديث Service Worker.

إضافات أخرى:
- تفسير ميسر للآية المختارة عبر معرف ar.muyassar من Al Quran Cloud إذا كان متاحًا في الخدمة.
- متابعة ختمة مرتبطة بآخر صفحة قراءة وهدف صفحات يومي.
- صفحة رقية تعرض الفاتحة وآية الكرسي وآخر آيتين من البقرة والمعوذات من نص القرآن.
- التاريخ الهجري عبر AlAdhan مع التنبيه إلى احتمال اختلافه بحسب رؤية الهلال.

مصادر خارجية مستخدمة:
- القرآن والنصوص والتلاوات المتاحة: https://alquran.cloud/api و https://alquran.cloud/cdn
- مواقيت الصلاة والتاريخ الهجري والقبلة: https://aladhan.com
- بيانات الأذكار: https://github.com/YousefAsalya/Islamic-Pro-azkar-API (MIT بحسب ملف المشروع)
- الموسوعة الحديثية: https://dorar.net/hadith (للبحث الخارجي فقط؛ لم ننسخ قاعدة بياناتها)

مزايا لا يمكن الادعاء باكتمالها في موقع GitHub Pages وحده:
- الأذان التلقائي الكامل في الخلفية حتى بعد إغلاق المتصفح يحتاج تطبيق Android أصلي أو خدمة إشعارات خلفية موثوقة.
- بيانات الموسوعة الحديثية الكاملة تتطلب موافقة وبيانات API من الدرر السنية وفق شروطهم.
- التلاوات المتاحة في API تتغير حسب فهرس الخدمة، ولذلك لا نضمن وجود كل اسم قارئ مطلوب قبل فحصه من داخل المشغل.
- النص صفحة بصفحة مستند إلى metadata الخدمة، لكنه ليس صورة طبق الأصل من صفحات مصحف المدينة ولا ينبغي اعتباره مطابقة طباعية دقيقة.


تحديث تنبيهات الصلاة والصوت (نوفمبر 2026):
- المدينة الافتراضية: Mallawi – Minya – Egypt. يمكن تغييرها من خانة المدينة.
- مواقيت الصلاة تُجلب من AlAdhan بطريقة الحساب المصرية (method 5). قد تختلف دقائق بسيطة عن توقيت المسجد المحلي.
- زر «تفعيل تنبيهات الصلاة» يطلب إذن إشعارات المتصفح ويجدول تنبيه الصلاة القادمة أثناء بقاء الموقع مفتوحًا. لا يمكن ضمان التنبيه أو تشغيل الأذان بعد إغلاق الموقع أو إيقاف المتصفح؛ GitHub Pages وحده لا يوفر خدمة تنبيهات خلفية موثوقة.
- زر «تجربة صوت الأذان» يشغّل تسجيلًا من Wikimedia Commons (CC0): https://commons.wikimedia.org/wiki/File:Adhan.ogg. تشغيل الصوت تلقائيًا وقت الصلاة قد تمنعه إعدادات المتصفح.
- التلاوات تُحمّل من Al Quran Cloud. يمكن اختيار أي قارئ يظهر في القائمة؛ تشغيل السورة يتم آيةً آية. توثيق المصدر: https://alquran.cloud/cdn
- الأحاديث الحالية مجموعة مختارة مع مصادرها ودرجاتها. الربط المباشر بواجهة الدرر السنية يتطلب تقديم طلب رسمي والحصول على API token ومراجعة الاستخدام قبل النشر؛ لا يجوز سحب قاعدة البيانات كاملة. التفاصيل: https://dorar.net/index.php/api-services/hadith
